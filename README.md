# Campaign Strike

Single-file static landing page for the Campaign Strike pilot waitlist.

## Deploy

Push `index.html` to the `main` branch of a public GitHub repository, then enable GitHub Pages with source set to `main` and `/ (root)`. The page will be available at `https://<account>.github.io/campaign-strike/`.

## Form setup

The form posts directly to FormSubmit at `carsonshef11@gmail.com`. FormSubmit sends a one-time activation email after the first submission; open that email (including spam) and click its activation link before relying on submissions. No API key or secret is stored in this site.
